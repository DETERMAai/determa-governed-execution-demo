# FAQ

## Is DETERMA an AI agent framework?

No.

DETERMA focuses on governed execution and execution authority boundaries.

---

## Is DETERMA a sandbox?

No.

The system focuses on governing whether execution should be allowed before mutation occurs.

---

## What problem does the public demo demonstrate?

The public showcase demonstrates how AI generated actions can be constrained through governed execution flows.

---

## Does the AI system receive direct mutation authority?

No.

The core principle demonstrated is that execution legitimacy is determined externally.

---

## Is this the full DETERMA system?

No.

This repository intentionally represents only the public showcase layer.

---

## Who is this repository intended for?

- enterprise architects
- security practitioners
- AI infrastructure researchers
- technical investors
- design partners
