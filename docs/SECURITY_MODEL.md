# Public Security Model

## Core Principle

AI generated intent is separated from execution authority.

The public showcase demonstrates how execution can be governed before real mutation is allowed.

---

## Public Demonstration Areas

The showcase demonstrates concepts around:

- constrained execution
- execution boundaries
- replay blocking behavior
- append only lineage
- verification before execution
- fail closed behavior

---

## Public Runtime Assumptions

The AI system itself is not treated as a trusted execution authority.

Execution legitimacy is evaluated externally.

---

## Public Scope

This document intentionally omits deep protocol semantics and private implementation details.
